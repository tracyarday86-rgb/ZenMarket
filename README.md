#  ZenMarket Pro

ZenMarket Pro is a full-stack e-commerce store built for selling tech gadgets. It includes a modern product catalog, dynamic search and filtering, a shopping cart, a 4-step checkout workflow with test payments, custom login, and a live admin dashboard.

##  Features

* **Product Catalog:** High-tech gadgets with instant text search and category filters.
* **Shopping Cart:** Add/remove items and edit quantities with live subtotal updates.
* **Multi-Step Checkout:** 4-step process (Sign In → Shipping → Payment Form → Receipt).
* **Admin Panel:** Real-time revenue analytics, order counts, and order logs.


##  Tech Stack

* **Frontend:** React, HTML5, CSS3, Axios
* **Backend:** Node.js, Express.js
* **Hosting:** Render / Vercel
